Asset tree

Locations as the API stores them — site, building, floor, room — with the assets recorded against each one. Assets may hang from any level of the hierarchy.

Order board

Maintenance orders grouped by the workflow status the API reports. Only the transitions the order’s current status allows are offered, and only when the token’s role may write; the server remains the authority and its refusals are shown verbatim.

Audit timeline

The audit trail, newest first. It is append-only: the API only ever reads this table and the database refuses to update or delete its rows, so nothing shown here can be edited or removed after the fact.

There is no login flow: the API authenticates bearer tokens only. The token entered above is kept in this browser and sent as Authorization: Bearer <token>; “Forget token” removes it. Every figure on these pages comes from the API as it answered — nothing is filled in by the page itself.
